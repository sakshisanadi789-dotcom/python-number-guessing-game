# Python Number Guessing Game

A simple Python game where the computer picks a random number between 1 and 100, and the player tries to guess it.

## How to play

1. Open a terminal in this folder.
2. Run:
   ```bash
   python guessing_game.py
   ```
3. Enter your guesses.
4. The program will tell you whether your guess is too high or too low.
5. The game ends when you guess the correct number.
6. The total number of attempts is displayed at the end.

## Example

```text
Welcome to the Number Guessing Game!
Guess a number between 1 and 100.
Enter your guess: 50
Too low!
Enter your guess: 75
Too high!
Enter your guess: 68
Congratulations! You guessed the correct number in 3 attempts.
```
